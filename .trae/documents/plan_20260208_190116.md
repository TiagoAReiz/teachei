# Correção do Bug Visual no Filtro Mobile

O problema "parada branca na lateral" ocorre porque o componente `FilterPanel` possui larguras e margens fixas (`w-72`, `mx-4`) que conflitam com o container do menu mobile, causando vazamento de layout e sobreposição visual.

## Plano de Correção

1.  **Refatorar `FilterPanel` para Responsividade**:
    *   Remover as classes de layout fixo (`w-72`, `mx-4`, `my-4`, `rounded-[2rem]`) que estão aplicadas incondicionalmente.
    *   Utilizar prefixos responsivos (`lg:...`) para aplicar o estilo de "card flutuante" apenas no Desktop.
    *   No Mobile (padrão), o painel ocupará 100% da largura e altura do seu container (`w-full`, `h-full`), sem margens e sem bordas arredondadas excessivas, integrando-se perfeitamente ao estilo "gaveta" (drawer).

2.  **Ajustes Específicos**:
    *   **Mobile**: `w-full h-full bg-surface` (Preenchimento total).
    *   **Desktop**: `lg:w-72 lg:mx-4 lg:my-4 lg:h-[calc(100%-2rem)] lg:rounded-[2rem] lg:shadow-xl` (Card flutuante).

3.  **Verificação**:
    *   Garantir que no Desktop o visual permaneça idêntico (card flutuante).
    *   Garantir que no Mobile o filtro abra como uma gaveta limpa, sem margens brancas laterais ou overflow.

4.  **Commit**:
    *   Enviar as correções para o GitHub com a mensagem: `fix: mobile filter layout styling issues`.
