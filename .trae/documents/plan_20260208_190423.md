# Estilização de Dropdowns (Selects e Menus)

Vou refatorar os componentes de seleção para abandonar o estilo nativo do navegador e adotar a nova identidade visual "Radical/Glassmorphism" do site.

## 1. Novo Componente `Select` (Customizado)
Substituir o wrapper nativo `<select>` por um componente totalmente customizado (`div` + `button`):
- **Visual**:
    - **Trigger**: Botão arredondado (`rounded-full`), estilo "cápsula", com sombras suaves e efeitos de hover.
    - **Menu (Dropdown)**: Card flutuante com bordas super arredondadas (`rounded-3xl`), sombra colorida (`shadow-primary/10`) e animação de entrada (`scale-in`).
    - **Opções**: Itens com padding generoso, hover colorido e ícone de check para o item ativo.
- **Funcionalidade**:
    - Suporte a `value` e `onChange` (passando o valor direto, não o evento).
    - Fechamento ao clicar fora (click outside).
    - Scroll suave para listas longas.

## 2. Atualizar `SortDropdown`
Refatorar o componente de ordenação para alinhar com o novo design:
- Corrigir o posicionamento do menu desktop (atualmente hardcoded) para ser relativo ao botão.
- Aplicar os mesmos estilos de card flutuante e itens do novo `Select`.

## 3. Atualizar Usos no `FilterPanel`
Adaptar o painel de filtros para usar o novo componente `Select`:
- Atualizar os handlers `onChange` para receber o valor string diretamente (ex: `e.target.value` -> `value`).

## 4. Revisão Geral
Garantir que todos os dropdowns (incluindo o de Notificações e Perfil, já ajustados) tenham consistência visual (sombras, bordas, cores).
